## 第一阶段：项目诞生与 CLI 基础（2026年1月5日 — 2月中旬）

**关键词**：初始架构、TUI 基础、MCP、自更新

项目始于2026年1月5日，首个提交 `b848fe16` 建立基础编码代理。核心功能逐步落地：

- **初始工具**：multi-edit、patch、webfetch、websearch
- **客户端/服务器架构**：双向通信、基于 Arc 的批量工具注册表、会话隔离
- **TUI 渲染**：流式消息队列、实时状态显示、内联工具调用渲染、差分显示
- **Claude 集成**：通过 Anthropic Agent SDK 桥接，后改为直接 API
- **MCP 支持**：模型上下文协议客户端，运行时服务器管理
- **自更新**：`jcode update` 命令与自动更新检查
- **扩展思考**：支持 Claude Opus 模型扩展思考，显示思考时长
- **后台压缩**：RAG 支持的上下文压缩系统
- **热重载**：自开发模式下热重载无缝切换二进制

**关键提交主题**：消息队列、状态行、滚动指示器、中断处理、TUI 非阻塞渲染、差分显示优化、协议类型化、终端集成

| 维度 | 轨迹 |
|-----------|--------|
| **界面** | 纯 CLI → 全功能 TUI → 桌面原生应用（空间面板、文件浏览器） |

| **SDK** | 无 → Rust/TypeScript SDK（生命周期、模式验证） |
| **背景** | 无 → 背景任务、停滞检测、进度报告、后台行渲染 |
| **代码库** | 单体 → 模块化 workspace（80+ crate） |
| **移动端** | 无 → iOS 应用（Swift、TestFlight、QR 配对） |
