# Jcode 版本演进路径

## 第一阶段：基础与 CLI 基础（2026年1月 — 2026年6月）

项目始于2026年1月5日。最初的提交建立了一个基础编码代理：多编辑、补丁、网页抓取和网页搜索等工具，搭配客户端/服务器架构。早期（预发布阶段）的重点包括：

- **核心架构**：双向通信的客户端/服务器、基于 Arc 的批量工具注册表
- **TUI 基础**：流式消息队列、实时状态显示、内联工具调用渲染
- **Claude 集成**：通过 Anthropic 的 Agent SDK 桥接实现第一方提供商支持
- **MCP 支持**：模型上下文协议客户端，运行时服务器管理
- **自更新**：`jcode update` 与自动更新检查
- **Swarm 前身**：会话和开放式代码风格的任务/待办工具

## 第二阶段：Swarm 与性能（v0.34.0 — v0.36.0，2026年7月2日—5日）

首个结构化的 changelog 条目以 **Swarm 内联渲染**和**实时任务图**为标志。该阶段确立了：

- **Swarm 编排**：子代理 now spawn inline，附带实时图库视口、深度模式下的实时 Mermaid 任务图，以及可选的 `run_plan` 进度报告
- **内存优化**：针对图像负载、会话搜索索引 Bloom 过滤器、glibc mmap 固定和堆修剪的激进削减（合计节省约 50MB+）
- **图像管线**：端到端解码、解压后的负载释放、缓存条目自愈
- **提供商解耦**：运行时移出基础 crate，大幅减少提供商相关编辑的编译次数

## 第三阶段：发现、提供商扩展与跨平台支持（v0.37.0 — v0.40.0，2026年7月7日—10日）

- **赞助工具发现**：`discover_tools` 工具，用于浏览和集成第三方服务
- **提供商网络扩展**：Cursor 提供商修复、Amazon Bedrock JSON Schema 支持、Claude Sonnet 5 推理力度
- **iOS 应用**：生产就绪图标与 TestFlight 自动分发
- **并行浏览器控制**：浏览器窗口绑定，允许多代理并发工作
- **待办评分**：目标级 hill-climbability 分数，区分可衡量目标与品味驱动型目标
- **轻主题**：自动浅色背景检测与自适应颜色

## 第四阶段：规划质量与 LaTeX（v0.41.0 — v0.45.0，2026年7月10日—13日）

- **待办质量门禁**：结构化反馈循环、可衡量目标、可追溯性要求和端到端所有权验证
- **LaTeX 渲染**：默认作为终端图像渲染，支持可靠的多行输出
- **拖放图像**：将图像文件直接放入编辑器
- **紧凑卡片**：待办和 swarm 活动采用无边框紧凑卡片，更清晰的进度指示器
- **终端同步**：标题与待办会话标题同步，保留传统回退方案

## 第五阶段：诊断、Windows 与安装可靠性（v0.46.0 — v0.50.0，2026年7月13日—17日）

- **发现增强**：建议缺失目录能力，用于审查的服务端诊断
- **Windows 生产就绪**：签名的安装程序、启动器、全局热键、生产级安装文档
- **安装弹性**：验证签名的发布元数据，当 GitHub 限流时回退到镜像
- **会话接管**：会话选择器可接管实时 Claude Code 会话（不仅是已完成会话）
- **Gmail 集成**：草稿操作在终端内直接显示完整预览

## 第六阶段：订阅、模型目录与终端面板（v0.51.0 — v0.55.0，2026年7月18日—22日）

- **订阅系统**：`/subscribe` 命令、Jcode Bedrock 订阅层级、Pro Max 和 Ultra 识别
- **模型目录扩展**：扩展的 Bedrock 目录、Claude Opus 5 内置、针对每个模型的最大 token 限制
- **终端面板**：通过 tmux 在分割面板中生成，而非全新窗口
- **规划精炼**：意图收集提升至计划级别，而非逐项；反馈循环可追溯性
- **无表情符号模式**：通过配置保持回复无表情符号

## 第七阶段：桌面应用问世（v0.56.0 — v0.65.0，2026年7月22日 — 8月2日）

- **桌面应用**：首个桌面版本，包含多会话工作区导航、原生数学排版、持久计划、模型选择和图像预览
- **SDK 演进**：Rust SDK 支持自有启动、全局生命周期事件、模式验证的结构化运行和运行时文件管理；TypeScript SDK 保持功能对等
- **桌面2**：热重载应用代码，无需重建窗口；Vim 风格恢复导航
- **无缝自更新**：实时进度条，下载完成后优雅原地重载
- **固定待办**：滚动时待办事项固定在视口顶部
- **终端分叉**：分叉会话遵循活跃终端环境（Ghostty、tmux、Zellij、GNU Screen）

## 第八阶段：桌面工作区与隐私（v0.66.0 — v0.76.0，2026年8月2日—14日）

- **桌面工作区**：项目文件浏览器、应用内帮助覆盖层、空间面板，支持新标签快捷键和动画导航
- **转录遥测**：可选、隐私保护，包含自动秘密编辑
- **提供商扩展**：Anthropic 兼容配置文件、Grok Build 在 TUI 内完成登录、Z.AI 推理力度控制
- **订阅与定价**：Jcode 订阅默认在引导流程中提供，内联模型选择器，按使用量计费的定价
- **引导流程**：基于订阅的引导流程，包含托管模型折扣和定价透明度

## 第九阶段：背景可见性与认证（v0.77.0 — v0.77.1，2026年8月17日至今）

- **背景任务可见性**：背景任务显示在固定状态栏中，报告中间进度，停滞时自动唤醒代理
- **认证扩展**：Cursor 和 Grok Build 原生认证流程，OrcaRouter 提供商配置文件
- **账户标识**：重复提供商账户在账户选择器中获得可记忆的动物名称
- **维护者反馈**：经明确同意后的隐私保护反馈提交
- **UI 交互**：可点击的固定待办、复制和编辑扩展徽章；搜索找到迟到的转录内容

---

## 关键演进主题

| 维度 | 轨迹 |
|-----------|--------|
| **界面** | 纯 CLI → 全功能 TUI → 桌面原生应用（空间面板、文件浏览器） |
| **提供商** | 仅 Anthropic → 6+ 提供商家族（OpenAI、OpenRouter、Gemini、Cursor、Grok、Copilot 等） |
| **协作** | 单代理 → Swarm 编排（图表、门禁、深度模式） → 松耦合代理 |
| **质量** | 隐式待办 → 结构化规划（可衡量目标、反馈循环、可追溯性） |
| **平台** | Linux → macOS → Windows 签名构建 → iOS → FreeBSD |
| **隐私** | 无 → 可选遥测、秘密编辑、同意控制 |
| **SDK** | 无 → 具有生命周期和模式验证的 Rust/TypeScript SDK |
| **背景** | 无 → 背景任务、停滞检测、进度报告、背景行渲染 |
